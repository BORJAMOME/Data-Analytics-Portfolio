# Regresión Lineal Múltiple — Retención clientes gimnasio

Predecir la asistencia de un cliente a partir de múltiples características demográficas y de comportamiento.

---

## Dataset

`dataset_didactico_machine_learning - ALUMNOS.xlsx` — variables demográficas y de comportamiento.

## Técnica aplicada

Regresión Lineal Múltiple con preprocesado (dummies, escalado). Feature engineering y evaluación cruzada.

## Librerías principales

- `pandas`
- `matplotlib`
- `scikit-learn`

## Cómo ejecutar

```bash
# Desde la raíz del repositorio
cd 03-Machine-Learning/01-supervisado/regresion/regresion-lineal-multiple/02-gimnasio

# Activar entorno virtual
python -m venv .venv
.venv\Scripts\activate      # Windows
source .venv/bin/activate    # Linux/Mac

# Instalar dependencias
pip install pandas matplotlib scikit-learn jupyter

# Abrir el notebook
jupyter notebook notebook.ipynb
```
