# Regresión Lineal Simple — Salud pacientes gimnasio

Estimar una variable continua de salud a partir de un predictor único en un gimnasio.

---

## Dataset

`Patient_Health_ALUMNOS.csv` — datos de salud de clientes.

## Técnica aplicada

Regresión Lineal Simple. Análisis de residuos y validación de supuestos (linealidad, homocedasticidad, normalidad).

## Librerías principales

- `pandas`
- `matplotlib`
- `scikit-learn`
- `scipy`

## Cómo ejecutar

```bash
# Desde la raíz del repositorio
cd 03-Machine-Learning/01-supervisado/regresion/regresion-lineal-simple/02-gimnasio

# Activar entorno virtual
python -m venv .venv
.venv\Scripts\activate      # Windows
source .venv/bin/activate    # Linux/Mac

# Instalar dependencias
pip install pandas matplotlib scikit-learn scipy jupyter

# Abrir el notebook
jupyter notebook notebook.ipynb
```
