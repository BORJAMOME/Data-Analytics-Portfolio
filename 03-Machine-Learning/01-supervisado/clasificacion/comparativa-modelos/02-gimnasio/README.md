# Comparativa 3 modelos — Gimnasio

Aplicar la misma metodología de comparativa de 3 modelos al caso del gimnasio para validar consistencia.

---

## Dataset

`dataset_didactico_machine_learning - ALUMNOS - copia.xlsx`.

## Técnica aplicada

Regresión Logística + Árbol de Decisión + Random Forest. Comparativa de métricas.

## Librerías principales

- `pandas`
- `matplotlib`
- `scikit-learn`

## Cómo ejecutar

```bash
# Desde la raíz del repositorio
cd 03-Machine-Learning/01-supervisado/clasificacion/comparativa-modelos/02-gimnasio

# Activar entorno virtual
python -m venv .venv
.venv\Scripts\activate      # Windows
source .venv/bin/activate    # Linux/Mac

# Instalar dependencias
pip install pandas matplotlib scikit-learn jupyter

# Abrir el notebook
jupyter notebook notebook.ipynb
```
