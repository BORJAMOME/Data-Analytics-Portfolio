# Regresión Logística — Predicción churn gimnasio

Identificar clientes con alta probabilidad de darse de baja de un gimnasio a partir de su comportamiento.

---

## Dataset

`dataset_didactico_machine_learning - ALUMNOS - copia.xlsx`.

## Técnica aplicada

Regresión Logística binaria. Matriz de confusión, curva ROC-AUC, precision y recall.

## Librerías principales

- `pandas`
- `matplotlib`
- `scikit-learn`

## Cómo ejecutar

```bash
# Desde la raíz del repositorio
cd 03-Machine-Learning/01-supervisado/clasificacion/regresion-logistica/01-gimnasio

# Activar entorno virtual
python -m venv .venv
.venv\Scripts\activate      # Windows
source .venv/bin/activate    # Linux/Mac

# Instalar dependencias
pip install pandas matplotlib scikit-learn jupyter

# Abrir el notebook
jupyter notebook notebook.ipynb
```
