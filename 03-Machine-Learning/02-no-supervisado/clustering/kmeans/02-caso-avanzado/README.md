# K-Means — Segmentación avanzada gimnasio

Segmentar clientes de un gimnasio con múltiples variables para diseñar campañas de marketing personalizadas.

---

## Dataset

`dataset_didactico_machine_learning - ALUMNOS - copia.xlsx`.

## Técnica aplicada

K-Means multivariante con escalado previo. Análisis de perfiles resultantes por clúster.

## Librerías principales

- `pandas`
- `matplotlib`
- `scikit-learn`

## Cómo ejecutar

```bash
# Desde la raíz del repositorio
cd 03-Machine-Learning/02-no-supervisado/clustering/kmeans/02-caso-avanzado

# Activar entorno virtual
python -m venv .venv
.venv\Scripts\activate      # Windows
source .venv/bin/activate    # Linux/Mac

# Instalar dependencias
pip install pandas matplotlib scikit-learn jupyter

# Abrir el notebook
jupyter notebook notebook.ipynb
```
