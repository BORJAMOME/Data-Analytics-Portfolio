# Manuales de Referencia

4 manuales de estudio propio, con formato didáctico: explicación → analogía → código →
explicación línea a línea → error común → aplicación profesional → ejercicio con solución.
Se conservan como referencia de librería, no como casos de negocio.

| Manual | Contenido |
|---|---|
| [Matplotlib](01-matplotlib/) | 10 tipos de gráfico + personalización + cheat sheet |
| [NumPy](02-numpy/) | Arrays, broadcasting, agregación, boolean masking, aleatoriedad |
| [Pandas — Limpieza de datos](03-pandas-limpieza-datos/) | Pipeline completo sobre un dataset "sucio" realista |
| [Pandas + NumPy — Fundamentos](04-pandas-numpy-fundamentos/) | Teoría + caso guiado paso a paso |
