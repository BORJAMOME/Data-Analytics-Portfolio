# Pandas — Limpieza de datos (manual completo)

Todo el manual trabaja sobre un único dataset "sucio": un export de CRM con duplicados,
nulos, texto inconsistente, números con símbolo de moneda, fechas en varios formatos, edades
imposibles y emails mal escritos. Recorre el diagnóstico inicial, los duplicados exactos y
"lógicos", los nulos, la normalización de texto, la conversión de tipos, los outliers de
negocio y la validación con regex. Termina con un pipeline de limpieza de principio a fin.

**Archivo:** `manual.ipynb` · **Stack:** pandas, NumPy
