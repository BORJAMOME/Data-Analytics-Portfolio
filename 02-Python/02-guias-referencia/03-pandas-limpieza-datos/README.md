# Pandas — Limpieza de datos (manual completo)

Manual construido sobre un único dataset "sucio" realista (export de CRM con duplicados,
nulos, texto inconsistente, números con símbolo de moneda, fechas en formatos mixtos, edades
imposibles y emails mal escritos). Cubre diagnóstico inicial, duplicados exactos y
"lógicos", nulos, normalización de texto, conversión de tipos, outliers de negocio,
validación con regex, y cierra con un pipeline de limpieza completo de principio a fin.

**Archivo:** `manual.ipynb` · **Stack:** pandas, NumPy
