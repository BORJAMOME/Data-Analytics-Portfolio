# NumPy — Guía completa

Manual de referencia: por qué existe NumPy frente a listas puras, creación y atributos de
arrays, indexado/slicing 1D-2D, operaciones vectorizadas, broadcasting, funciones de
agregación con `axis`, boolean masking y `np.where()`, datos faltantes (`NaN`), reorganizar
y combinar arrays, ordenación, y números aleatorios para simulación. Incluye 5 ejercicios
prácticos con solución.

**Archivo:** `manual.ipynb` · **Stack:** NumPy
