# Pandas + NumPy — Fundamentos y caso guiado

Manual en dos partes. La parte A es teoría: carga de CSV, EDA inicial, limpieza de nulos,
columnas derivadas y filtros, estadística básica, `groupby` y acceso con `iloc`/`loc`. La
parte B lo aplica paso a paso sobre el mismo dataset del caso de ventas por departamento,
con el clásico problema de dividir entre cero, percentiles y correlación.

**Archivos:** `manual.ipynb`, `ventas_empleados.csv` · **Stack:** pandas, NumPy
