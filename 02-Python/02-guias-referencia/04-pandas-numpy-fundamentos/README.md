# Pandas + NumPy — Fundamentos y caso guiado

Manual en dos partes: **Parte A** (teoría) cubre carga de CSV, EDA inicial, limpieza de
nulos, columnas derivadas y filtrado, estadística básica, `groupby` y acceso con
`iloc`/`loc`. **Parte B** aplica todo lo anterior a un caso guiado paso a paso (mismo dataset
que el caso de negocio de ventas por departamento), incluyendo el problema clásico de dividir
entre cero y cálculo de percentiles y correlación.

**Archivos:** `manual.ipynb`, `ventas_empleados.csv` · **Stack:** pandas, NumPy
